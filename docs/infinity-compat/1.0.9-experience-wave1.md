# Infinity 1.0.9 Experience Wave 1

Status: staged upper-layer feature branch. No native Kodi engine rebuild is required by this wave.

## Added

### Infinity Command Center
`script.infinity.commandcenter` exposes one system control surface for:

- manual restore-point creation and restore,
- Crash Quarantine correlation review,
- Performance Mode / Adaptive Refresh,
- Infinity Safe Mode / compatibility Auto,
- Health Center launch,
- runtime Hook/Skin inspector,
- skin reload and add-on settings.

The runtime inspector consumes the current Infinity Skin Theme Contract and Adaptive Layout API properties (`Infinity.Theme`, `Infinity.ThemeRevision`, `Infinity.DeviceMode`, `Infinity.Orientation`, `Infinity.WindowWidth`, `Infinity.WindowHeight`, `Infinity.Layout`, `Infinity.TouchClass`, `Infinity.MotionPolicy`, `Infinity.RefreshPolicy`, and `Infinity.PowerPolicy`). It does not create another display or theme detector.

### Restore Points
Restore Points are deliberately configuration-layer snapshots rather than full Kodi data clones. They include the core profile XML files plus Infinity/Diggz skin-shortcut and Infinity service settings. Cache, thumbnails, media databases, native libraries and installed add-on binaries are not copied.

Before a restore is applied the Command Center creates a `before-restore` safety snapshot. Restore ZIP paths are validated against absolute/path-traversal entries before extraction. The number of retained points is configurable from 2 to 10.

### Crash Quarantine
Crash Quarantine reads the existing `service.infinity.compat` unclean-start history. When an unclean start exists it correlates that timestamp against recently modified add-on directories within a configurable window. A correlated add-on may be disabled only after explicit user selection and confirmation.

A recent modification is evidence of timing only. The feature never reports correlation as proof of crash causation and does not automatically disable add-ons.

### Per-title playback memory
The service stores and restores the selected audio stream and subtitle state per movie or TV episode. Stream restoration first matches language/name and only falls back to a valid prior index. The memory store is bounded to the 500 most recently updated titles.

Playback speed is observed in the record for future compatibility work but Wave 1 does not force arbitrary speed values because Kodi's upper-layer JSON-RPC speed control does not expose a portable fractional-speed contract.

## Capability contract
`addons/service.infinity.compat/resources/capabilities.json` advances to schema 4 and advertises Experience API 0.1 with:

- `command_center`
- `restore_points`
- `crash_quarantine`
- `runtime_skin_inspector`
- `per_title_audio_subtitle_memory`

Existing Hook API 1.0, Skin API 1.0, Theme Contract 1.0 and Layout API 1.1 remain unchanged.

## Intentionally deferred

- touch gesture injection during full-screen playback,
- arbitrary per-title fractional speed,
- aspect/zoom restoration,
- automatic suspect disabling,
- cross-add-on Continue Watching aggregation.

Those need device/runtime validation or a stronger common identity contract before they should become default behavior.
