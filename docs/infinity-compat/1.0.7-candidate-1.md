# Infinity 1.0.7 Candidate 1

This candidate is intentionally isolated from the released 1.0.6 branch.

It targets the captured post-Stop Android SIGABRT in `CPythonInvoker::PyObjectDeleter` by correcting Python temporary-reference ownership and checking module-dictionary insertions. It does not suppress codec/player errors, disable add-ons, or claim an add-on caused the crash.

For Diggz/Xenon, a narrow Compatibility Guard preserves `Home.xml`, shortcuts, widgets, menus and artwork. It reasserts only a self-contained Infinity `VideoOSD.xml`, seek overlay and lock dialog, adds two Xenon color-theme files driven by Infinity's light/dark/system policy, and adds an optional `Infinity System` fontset. The guard keeps backups of the original Xenon player files. It does not provide a security sandbox against arbitrary add-on code.

The build also includes the bounded Android exit-history diagnostics prepared after 1.0.6, so a future crash can expose better process-exit evidence when Android retains it.

Passing CI proves source pinning, compilation, packaging, signature identity and structural gates. It does **not** prove the Stop crash is fixed or that the Xenon UI looks correct on-device. Required device tests: repeated Play -> Stop, audio/subtitles, lock/unlock, Diggz home unchanged, light/dark/system transitions, fold/rotation, and a Health Center export after any failure.
