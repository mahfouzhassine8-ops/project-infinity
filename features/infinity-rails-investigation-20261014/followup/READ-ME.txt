ONE-SHOT CAPTURE TOOL

Install script.infinity.railcapture-0.1.0-DIAGNOSTIC.zip through Install from ZIP.
This is a separate Program add-on, NOT a skin/helper replacement or repair.

1. If available, enable Kodi debug logging before the capture. The tool does
   not change that setting; restore your previous setting afterward.
2. Open Program add-ons > Infinity Rail Hold Capture > Run.
3. Choose Capture one rail hold. Confirm the instructions. It opens Home in
   the existing view mode. Hold the affected TV rail card ONCE.
4. Leave the popup visible for two seconds, then dismiss it normally. The tool
   saves after observing a window transition, or after a 30-second observation
   window. A blocked Kodi API call can delay completion during a UI stall.
5. Run Infinity Rail Hold Capture again, choose Export latest capture, and
   select a writable folder such as your configured Downloads source.
6. Attach the resulting Infinity-Rail-Hold-YYYYMMDD-HHMMSS.zip here.

The ZIP contains current skin/helper/Super Favourites versions, relevant
installed source, system/profile input keymaps, Home/card/popup transitions,
and up to the last 1 MiB of kodi.log. It intentionally does not collect add-on
settings, rail preferences, databases or authentication stores. Logs/keymaps
can contain private paths or commands; nothing is uploaded automatically.

No skin/add-on/keymap is patched. No service is installed. Observation occurs
only when explicitly started and records state changes at 100 ms intervals
within that short capture. It does not issue clicks, close the black popup,
change playback or alter view/theme preferences. Export is user-selected.
Removing the standalone capture add-on afterward has no effect on Rails.
