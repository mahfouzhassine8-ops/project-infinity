INSTALLATION
1. Install script.infinity.rails-0.2.0-Custom-Rails-RC3-TEST.zip using Infinity's Install from ZIP. This upgrades the same helper ID and keeps its existing profile-local rails.json.
2. Install skin.infinity.diggz-1.0.5.218-Custom-Rails-RC3-TEST.zip through Install from ZIP. This is a complete skin package, including every baseline font, artwork asset and unrelated resource. Do not uninstall Infinity or the skin.
3. Allow the normal skin reload; if Kodi asks, confirm the reload. There is no Program add-on patch application step.
4. Movies/TV Shows → All Add-ons → press and hold an installed video add-on → Add to Infinity Rails → Movie Add-ons, TV Show Add-ons, Both Rails or Cancel.
5. On an existing rail, tap to launch. Press and hold for Open Add-on, Move / Reorder, removal of a user-added shortcut, supported add-on settings or Cancel. Back/X dismisses. Built-in shortcuts have no removal action.

MENU OWNER AND ROOT-CAUSE FINDING
RC2 supplies list-item context actions to Kodi's directory provider; intentional long-press opens the existing DialogContextMenu.xml. It never shipped a Rails-owned menu layout. The .215 unified context layout nests the background, auto-height group list and cloned button template under percentage-sized groups, with a 90%-height parent. Other profiles retain fixed legacy menu dimensions. Native Kodi's context-menu controller sizes and positions the dialog using background 999 and list 996, and clones template 1000. This combination is vulnerable to a mismatch between the nested percentage frame and the background/list sizing contract; it is the source-level sizing defect addressed here.
The supplied screenshot confirms a malformed legacy-looking popup, but does not identify which cached installed XML resource Kodi actually loaded. No physical-device log was available. The precise device-side resource/cache contribution is therefore unconfirmed.
RC3 adds an exclusive Rails/add-on context branch with top-level native contract controls, a content-sized background, a bounded scrolling action list, readable theme-aware typography, rounded original Infinity textures and X. Native Kodi clamps the popup to its current coordinate viewport. The exact original controls survive in a separate include used for other context menus. No native or global context-menu action behavior is replaced.
The header identifies the selection through the first native action label (Open Add-on · selected name), avoiding reliance on an absent ListItem in the open context dialog. Other add-on browser context actions remain available.
