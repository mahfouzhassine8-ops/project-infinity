INFINITY CUSTOM RAILS RC3 — TEST CANDIDATE, NOT LOCKED

INSTALL IN THIS ORDER
1. Infinity > Install from ZIP: script.infinity.rails-0.1.2-RC3-TEST.zip.
   This upgrades the existing script.infinity.rails helper in place.
   Do not uninstall the old helper. Do not run a Program add-on patch tool.
2. Install from ZIP: skin.infinity.diggz-1.0.5.217-Custom-Rails-RC3-TEST.zip.
   This is a complete normal skin ZIP, with the same skin ID.
3. Allow Kodi to finish installing; reload the skin if requested.
4. Keep the APK currently installed. No APK update is part of this candidate.

The Rails helper is a declared required dependency at version 0.1.2.
It is not published in an available repository for automatic resolution.
Install the provided helper first or Kodi may refuse the skin dependency.
Other pre-existing .215 dependencies remain unchanged.

USE
Movies/TV Shows > All Add-ons > long press an installed video add-on >
Add to Infinity Rails > Movie Add-ons / TV Show Add-ons / Both Rails.
On a rail card, a normal tap launches it. Long press requests Rails Options.
Removal affects only that rail shortcut. The add-on remains installed.
Built-in cards have no removal option. Move / Reorder chooses a destination.
Menus page in very short windows; Back or X always dismisses.
A fold/resize safely dismisses the menu without changing saved data.
