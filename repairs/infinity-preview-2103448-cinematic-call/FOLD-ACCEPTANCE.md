# Physical Fold acceptance — Preview only

Install the testing APK directly over 448. Keep the protected 448 download. No
uninstall, data clearing or settings reset is required.

1. Open two familiar videos through the existing Infinity Preview handler. Check
   Resume and Start Over, pause/play, independent seeking, ±10 seconds, Stop,
   Close/Back, Audio, Subtitles, Display, rotation and the original Volume dialog.
   Swipe the control strip to reach its end. Return to the originating app.
2. Compare cinematic appearance with the approved image on the inner display;
   check cover/inner and landscape, Light/Dark/System, readable controls, video
   aspect ratio, scrolling and theme changes without losing progress.
3. During an active call, open a video: it should move while muted. Tap Unmute if
   media sound is wanted; Android, Samsung or the call app may still enforce
   silence. Check incoming-call transitions, manual Mute, preserved private
   volume and normal behavior after the call. A paused video must stay paused;
   a backgrounded Preview must retain its existing pause behavior.
4. Confirm normal launcher/chooser, Kodi and Cobra remain as accepted. Their
   protected payload is compared byte-for-byte; no new unrelated behavioral or
   shutdown test is part of this work.

Only the user can accept and lock the testing release after these observations.
