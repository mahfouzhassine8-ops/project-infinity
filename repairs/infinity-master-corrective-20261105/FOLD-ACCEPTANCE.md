# Physical acceptance — pending implementation/release gates

Do not install the current source checkpoint. No signed candidate exists for this workstream. First satisfy REMAINING-GATES.md, verify the actual installed package/certificate/version, retain the frozen recovery baselines, and produce/verify the authorized forward-recovery APK. An unresolved write/checkpoint is not permission to force termination.

For the eventual completed candidate, record version, source/module/skin generations, device model/API, usable window bounds/insets and selected theme/view. Exercise cover and inner displays, portrait and landscape, supported fold/unfold and window resizing. Host results do not mark these physical cases PASS.

1. Search: Crew and Nixtoons TV searches plus a working control provider; fresh/cache paths, normal widget activity, ordinary history/timing writes, meaningful configuration change, provider update/disablement, cancel and consecutive submissions. Record the original request outcome and privacy-safe changed-state reasons. No automatic retries or raw queries/credentials in diagnostic exports.
2. Direct drawer entries: Movies opens installed Umbrella Movies; TV opens Umbrella TV; Sports opens the actual installed SportHD root; Favorites opens native saved destinations. No intermediate menu/substitute. Verify existing loading feedback, Back/focus and independent indexed-library entries.
3. Drawer: in portrait, open at the original top position; Power is the last full visible row below System Hub; Explore and all later content scroll normally. In landscape, preserve row sizes and normal scrolling, as the user explicitly selected. One Power entry/action, no pin or duplicate. Verify short landscape separately; do not accept max-height arithmetic as device evidence.
4. Browser: compare the actual approved PNG with rendered output after its SHA is verified. Test compatible Umbrella, Red Light, Crew, Nixtoons and Otaku media plus indexed Movies/TV, files and Favorites. Use real selected-item art/metadata, missing-art cases, folder rows, long titles/plots and no enlarged directory/Trailers fallback. Preserve every supported view and registered fallback.
5. Touch: first tap selects, second tap activates once, hold opens the existing context menu once; include untyped provider folders, episodes, files, native Favorites and poster/list layouts. A hold must not start playback. Back preserves the expected item/scroll location. Close/Back/Power and modal buttons remain direct actions; remote/keyboard coexist.
6. Existing global List/Posters/InfoWall/TriPanel preference: providers, categories, pagination, Back, refresh, reopen and restart; incompatible windows fall back without overwriting the saved choice. Verify artwork/details and contextual actions.
7. Library: indexed Movies/TV retain watched/resume/metadata; Browse Files uses the normal native video-source browser; navigate an already authorized Downloads folder, play through Kodi and return to the folder. Check existing audio/subtitle/resume controls without modifying files or permissions. Denied storage access must be recoverable.
8. Light/Dark: change the existing theme and verify actual browser, drawer, selected/focused/unselected rows, details and controls; no second theme system. Playback handoff, loading/cancel, background return and navigation must retain their existing owners.

No unrelated shutdown suite or Scudo claim is part of this acceptance list. No automatic installation, release acceptance or lock.
