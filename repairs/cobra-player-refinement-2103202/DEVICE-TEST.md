# Physical-device acceptance — 2103202

Not completed by automated tests. Record device/model, Android version, installed version, source/channel aliases and time; do not share credentials or full stream URLs.

1. Install as an update over locked 2103201. Confirm settings, sources, favorites, recents and recordings remain. Do not uninstall or clear data if an update/downgrade is rejected.
2. Test real captions on one known captioned stream and one without captions. Tap the glyph, text and row edge for Off and English; repeat 20 times. Check immediate Off, supported track selection, no stale cues, no double actions. Change preferred audio while captions are manually enabled, and vice versa. Reopen and restart to verify saved preferences.
3. Check subtitle sizes, long multiline text and bitmap captions. Resize inner/cover display, split-screen and PiP; compare adaptation On/Off. Verify readability and complete captions, not only preference values.
4. Hold and drag the timeline at live, halfway back and the earliest boundary. Live shade/end marker must differ from the playback position in Light, Dark, OLED and Follow System. Holding must not open Channels. Release once, cancel once, use D-pad/accessibility, pause while rewound, jump live and switch channels. Provider catch-up must not label its archive endpoint as current live.
5. Test each display mode individually on 16:9, 4:3 and portrait video. Fold Adaptive must fit the complete frame into the actual usable window without stale dimensions, cropping or distortion. Proportional-fit bars are expected when source/window shapes differ. Test inner/cover, both orientations, split-screen resizing, lock/unlock, PiP and return. Keep menus open during resize; rows must remain reachable.
6. Start 2, 3 and 4 Multi-View tiles. Select a non-first audio owner and pause another tile. Leave to PiP and return via expansion, Recents and the app icon. Restore order, audio owner and paused tile. Repeat 10 cycles. Only one video/audio stream may be presented in PiP. Dismiss PiP and reopen: restore layout without unwanted autoplay. Remove one tile manually and ensure it does not return. Check source removal/profile changes do not resurrect invalid content.
7. For one channel test PiP, background audio and rewind at Inherit/On/Off, then test an untouched channel. PiP takes precedence when eligible; disabling it with background enabled should retain only the selected audio session and native media controls. Disable both: playback pauses. Test media Play/Pause/Stop, headphones removal, audio interruption, notification refusal and background/foreground cycles.
8. Use Restart live playback on a stalled channel, ordinary live and rewound playback. Verify reconnection at live without clearing language/display preferences, sources or history. Test both preview and fullscreen. Verify Reset this channel remains distinct.
9. In Channel playback, Recents must match existing channel history. Display appears in the video toolbar, language preferences only in Audio & subtitles. Check touch and D-pad navigation, scrolling and focus through all added options.
10. In File picker test Ask, System and Files app by tapping glyph and label. Then open media and import a UI ZIP. Pick internal storage, Downloads, SD/storage providers and a compatible installed file manager if available. Cancel each path; reopen. Diagnostics save must still allow choosing a destination. Record the exact failing screen/provider if Android does not offer the expected location.
11. Compare known-good and problematic channels using the same network/provider settings as the locked baseline. Observe startup, pauses, long stalls, repeated channel switches and at least one long session. No general buffering improvement is claimed without these captures.
12. Check new diagnostic fields against actual active playback and confirm exported reports contain no credentials. Verify repeated open/close/PiP/resize cycles leave no hidden audio, stale overlays or growing player counts.

Finish by marking every item PASS / FAIL / NOT TESTED. A failure in playback, timeshift, PiP, Fold sizing or source handling blocks release acceptance even if CI is green.
