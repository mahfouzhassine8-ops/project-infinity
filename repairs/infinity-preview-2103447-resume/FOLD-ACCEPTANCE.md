# Physical Fold acceptance — Preview resume memory only

Install the signed candidate over the existing application. Do not uninstall,
clear data, change the original signer or modify the protected baseline.

1. Open two ordinary seekable videos longer than two minutes through a file
   manager. Seek A to a memorable position beyond 30 seconds, Pause, then Back.
   Open B at a different position, then Stop. Reopen each and check its own
   Resume prompt, actual picture, elapsed time and seekbar.
2. Choose Start Over for A. Reopen it and confirm it begins at zero while B
   retains its independent progress. Back from a pending Resume prompt must
   return to the source without erasing that video's saved position.
3. Pause/background the player, reopen the video, and check progress. Reboot the
   phone normally when convenient and reopen it again. Abrupt interruption can
   lose the last checkpoint interval (normally about 10 seconds).
4. Open the same accessible document through MiXplorer, Android Files, Samsung
   My Files or another compatible caller. Matching is supported when they
   expose the same document URI or the same granted backing file. Unrelated
   cloud objects/local downloads and unrelated opaque provider identities must
   not inherit each other's positions just because names match.
5. Finish a video, or seek into its last 30 seconds / final 5%, then close it.
   Reopening should start from the beginning. Brief progress below 30 seconds
   and live/nonseekable media should not produce a needless Resume prompt.
6. Try rapid A/B/C opens, an expired/revoked file grant and a normal background
   return. Verify current video identity, responsive Back/Stop and useful errors.
7. On cover and inner displays, check the original horizontal control strip,
   seekbar, Pause, ±10 seconds, Mute/Volume, Audio, Subtitles, Best Fit/Fill and
   rotation. The signed447 dark UI remains unchanged under Android system
   Light/Dark selection. The separate cinematic Light/Dark design is not part
   of this resume-only release.

No new shutdown tests are requested. Kodi history, Continue Playing and Cobra
are not used for this feature. Physical acceptance and any new lock belong to
the user; automated fixtures do not replace this acceptance.
