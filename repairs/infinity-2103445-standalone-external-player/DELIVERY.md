## Implemented behavior

The existing Splash video gateway routes compatible video requests to one private
Android framework player in `:externalplayer`. Actual decoding does not initialize
Kodi. Latest-request ownership handles rapid file replacements without retaining
stale callbacks. Stop/Back/Close finish the external player and return to the source
when Android's task stack permits. Loading ends with preparation, failure or
cancellation. Play/Pause, seeking, per-player audio, supported audio/text subtitle
tracks, fit/fill and resize controls are included.

The application and launcher remain **Infinity**. Android's video VIEW/SEND handler
label is **Infinity Preview**. There is exactly one matching public video gateway,
no second application or launcher icon, and no exposed `PreviewActivity` label.
The original technical Splash class remains in place. The complete selector
coverage and formatting limits are in [LABEL-COMPATIBILITY.md](LABEL-COMPATIBILITY.md).
