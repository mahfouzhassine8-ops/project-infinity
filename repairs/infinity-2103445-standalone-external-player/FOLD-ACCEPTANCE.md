# 2103447 physical Fold acceptance

Candidate only. Do not lock or promote before the user's acceptance. Retain
original-key signed 2103445 as recovery; do not uninstall or clear application data.

1. Install the combined signed APK over the current installation. Check that the
   application and launcher still say **Infinity**, with one launcher icon.
2. Open a granted local MP4 using MiXplorer, Samsung My Files, Android Files or
   Downloads. Where the source presents handler metadata, check **Infinity** /
   **Infinity Preview** and one Infinity video entry. The technical gateway is
   still Splash. A chooser that ignores intent-filter labels or displays raw
   class names may show a different subtitle; capture the particular app/version.
3. Check real picture and audible audio, disappearance of loading after readiness,
   Play/Pause, seek, per-player mute/volume, available audio and text subtitle
   tracks, Best Fit/Fill and rotation. Check both Fold displays and supported
   split-screen/window resizing. Unsupported codecs/DRM/subtitles are not promised.
4. Use Stop, Android gesture Back and Close. They should leave only the external
   player and return to the source application when its task is still available.
   Open a second and third file, reopen the same file and select files rapidly.
   Confirm only the latest request plays, without a stale loading indicator.
5. Check background/foreground and screen off/on. The external player suspends
   decoding in the background; return should retain its in-memory position. It
   does not borrow Kodi/Cobra PiP or run a new background playback service.
6. Try a permitted Drive document or other cloud provider and a direct video
   URL. Authentication, temporary grants, provider seekability and Android media
   codec support still apply. A webpage is not necessarily a video stream. An
   inaccessible or unsupported request should show a local error and allow Back.
7. While an accepted Kodi or Cobra session is already present, open an external
   video. Check the existing session remains intact; the external player starts
   muted when an existing experience task is present. Deliberate Unmute uses
   Android audio focus. Check returning to the original experience and normal
   Infinity launcher / Choose Your Experience behavior.

Android emulator fixture evidence does not establish Samsung launcher/file-manager
presentation, audible Fold output, physical hinge behavior, private cloud account
access, or simultaneous native Kodi session behavior. Those remain device checks.
No shutdown test is included.
