# Preview 450 physical acceptance

Install over the existing build without uninstalling or clearing data. Retain
signed448 and449. Only the user can accept and lock a new candidate.

1. On cover/inner and landscape, open familiar wide, portrait and square videos.
   Check proportions, adjacent timeline/toolbar, system insets and no overlaps.
   Best Fit preserves the image; Fill crops only when explicitly selected.
   Tap video to hide controls and use the unobstructed viewport, then show them.
2. Scroll to rotation: Auto has persistent cyan feedback, Locked clears Auto's
   highlight. Toggle repeatedly, rotate, fold/unfold and return from background.
3. Check polished −10s/+10s icons and exact seek actions, inline volume, Mute,
   Audio, Subtitles, Display and accessible horizontal scrolling. There is no
   duplicate Volume button/dialog.
4. Verify Resume/Start Over and preserved call behavior: moving video defaults
   muted during an active call, with manual Unmute when Android permits it.
   Samsung/carrier/VoIP may enforce media silence. User Pause remains authoritative.
5. Close/Back returns to the source application. Main Infinity and Cobra remain
   the accepted experiences. Their frozen payload is checked by hashes; no new
   unrelated application or shutdown tests are selected.
