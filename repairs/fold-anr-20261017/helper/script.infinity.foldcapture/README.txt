INFINITY FOLD FREEZE CAPTURE 1.0.0 — EXPERIMENTAL DIAGNOSTIC HELPER

This helper does not fix the ANR. It arms the lock recorder already compiled
inside the exact locked Infinity 2103377 TEST4 engine for two hours. TEST4's
automatic startup window lasts only 90 seconds, which misses long background
returns. The existing eight-snapshot and 512 KiB recorder limits remain intact.
No APK rebuild, skin replacement, provider change or new background service.

INSTALL AND CAPTURE
1. In Infinity, use Install from ZIP to install this ZIP.
2. Open Infinity Fold Freeze Capture from Program Add-ons.
3. Select Arm capture for two hours before leaving Infinity.
4. Use other apps, return, dismiss the screensaver and try the navigation that
   froze. Do not request Close while waiting to reproduce a background return.
5. If Android stops the app, reopen Infinity once. Run the helper and select
   Export current and previous capture. Choose Downloads or another accessible
   folder. Export before reopening Infinity a second time, since the recorder
   retains only the current and previous process logs.
6. Keep that capture ZIP and the normal Infinity Android diagnostic ZIP from
   the same attempt. Both are needed to connect native lock ownership with
   Android's ANR timestamp and producing process. State the background duration.

The helper checks the exact loaded native library SHA-256 before calling the
existing Arm(int) function. A different engine is refused. It does not change
or release locks, reset user data, affect termination authorization, add a
service, keep the app alive, or replace Rails helper 0.2.5. Closing normally
remains governed by the approved Essential-First implementation.

Exports contain only the current/previous native recorder logs and a small
manifest of versions, checksums and producing PIDs. No provider settings,
credentials, databases or unfiltered Kodi logs are collected. Treat exports
as private diagnostic evidence. Missing snapshots are reported as unavailable.

VERIFICATION
Exact native exports and machine-code call sites were checked against the
locked APK. Host tests execute the original C++ Arm implementation and Python
helper with an actual host shared library. These are Linux host tests, not
proof that Android/Kodi can invoke this helper on the Fold. Physical validation
of the ctypes bridge, capture and export is still required.

The helper ZIP is a Kodi add-on archive, not a signed APK. Package integrity is
recorded by SHA-256. Keep APK 2103377 TEST4 and skin 1.0.5.223 installed.
